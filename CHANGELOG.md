# Changelog

## 0.9.1

- Added Flea to **Settings → File manager**. Selecting Flea opens managed SSHFS mounts in the installed `flea` executable.

## 0.9.0

- Added cached Fastfetch snapshots with per-host field selection, refresh on view, scheduled refresh and manual refresh. The System page can install Fastfetch over SSH when it is missing.
- Added system summaries to the wide host card and compact dock, with memory and disk usage bars and expandable details.
- Added a choice of SFTP file manager and support for opening direct SFTP URLs. Nautilus remains the default for SSHFS mounts.
